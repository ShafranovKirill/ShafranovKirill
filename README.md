## 👋 About Me

Full-stack engineer specializing in **reliable, well-structured systems** and **data-driven architectures**.
Most of my experience is in web development — building services with Elixir, Node.js and Postgres that scale and stay maintainable under real load.

- 🔭 Building scalable, observable and maintainable backend services
- 🧠 Interested in distributed systems, high-load patterns and database internals
- λ  Enjoy functional programming and clean system design
- 💬 Happy to chat about projects, collaborations or just tech
